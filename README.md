🔥 VIBECS2 Helper
Удобный помощник для игроков и администрации VIBECS2
VIBECS2 Helper — это современное desktop-приложение, созданное для быстрого доступа к правилам проекта, административной информации и полезным инструментам.
Приложение объединяет все необходимые материалы проекта в одном удобном интерфейсе, позволяя быстро находить нужные правила, изучать наказания и получать актуальную информацию без необходимости открывать браузер.

✨ Возможности

📚 База правил
- Полный список правил проекта;
- Удобная навигация по разделам;
- Быстрый поиск нужного пункта;
- Отображение наказаний и подробного описания.
- 
⚡ Быстрый доступ

- Мгновенный просмотр правил;
- Удобная система категорий;
- Компактный интерфейс для ежедневного использования.
- 
🎮 Для игроков

- Быстрое изучение правил проекта;
- Понимание возможных наказаний;
- Удобный справочник всегда под рукой.
- 
🛡 Для администрации

- Быстрый поиск нарушений;
- Удобный просмотр пунктов правил;
- Единая база информации для работы.
